# Импорт ТВ-программы на полосу газеты

Инструмент переносит программу передач из текстового файла на полосу
ТВ-программы в макете InDesign 2024 — **одной командой**.

---

## Приложение «Импорт ТВ 2.0»

Запуск: ярлык **«Импорт ТВ 2.0»** на рабочем столе.
Либо вручную:

```
pythonw.exe "D:\instal\Progect2026\9_InpurtTV\Импорт ТВ 2.0.pyw"
```

| Поле | Назначение |
|---|---|
| Файл программы | `program*.txt` из `D:\instal\Progect2026\8_Programs` |
| **Макет полосы** | путь к `Programs.indd`. Можно вписать вручную или выбрать кнопкой **«Обзор...»**. Путь запоминается между запусками |
| Понедельник недели | дата `ГГГГ-ММ-ДД`, например `2026-10-19` для программы с 19 по 25 октября |
| Дата выхода газеты | пусто = шапку полосы не трогать |
| **Значки каналов** | флажок «Выравнивать значки по срезу названия после импорта» (включён по умолчанию) |

Под макетом показываются размер, дата изменения и полный путь. Если файла нет —
надпись краснеет и импорт блокируется.

Кнопки:

| Кнопка | Что делает |
|---|---|
| **ПУСК** | основная кнопка: полный цикл — импорт программы, затем выравнивание значков (если флажок стоит) |
| Импортировать | то же, что ПУСК |
| Проверить (без изменений) | разбирает файл и печатает сводку, макет не трогает. InDesign не запускается, отклик мгновенный |
| **Выровнять значки** | только шаг значков, без импорта программы |
| **Создать PDF** | экспортирует выбранный макет в PDF (пресет High Quality Print) и открывает файл |
| Открыть отчёт | открывает последний `ОТЧЁТ_ИМПОРТА_ТВ_*.md` |
| Выход | закрывает приложение, запоминая выбранные пути и флажок |

Пока идёт работа, кнопки блокируются — повторный запуск невозможен.
Шаги выполняются по очереди в одном потоке: сначала импорт, потом значки.

Журнал работы идёт в окне приложения. Первый запуск при закрытом InDesign занимает
около двух минут (InDesign стартует сам), при открытом — около полутора минут.
Создание PDF при открытом InDesign занимает несколько секунд.
Выравнивание значков добавляет 20–60 секунд на проход (обычно один проход).

**Резервные копии и отчёты складываются рядом с макетом**, в `D:\instal\Progect2026\8_Programs`,
а не в папку приложения: автоматически хранятся 5 последних копий
`Programs_резерв_ГГГГММДД_ЧЧММСС.indd`, ручная `Programs_РЕЗЕРВ_ДО_ЗАМЕНЫ.indd` не трогается.
Снимки макета для шага значков — в `9_InpurtTV\_work\icons\backup` (3 последних).

### Шаг «Значки каналов»

Значки ПЕРВЫЙ, РОССИЯ 1, НТВ, ТВЦ, СЕЙМ ставятся ровно по **срезу названия канала**
(верхняя граница прописных букв), как в эталоне `Maket1.indd`:

```
срез прописной буквы = базлайн строки канала − 1,745 мм
```

Замер идёт по растру PDF 600 dpi, поэтому перед подгонкой макет сохраняется
и экспортируется. Значки двигаются **только по вертикали**, размер не меняется.
После подгонки колонки сверяются со снимком: число абзацев, символов и переливка
текста должны совпасть — иначе приложение предупредит.

Итог показывается в диалоге:

| Код шага | Что означает | Диалог |
|---|---|---|
| 0 | все значки в допуске 0,25 мм | «Значки каналов стоят по срезу названия» |
| 1 | работа сделана, но часть значков вне допуска 0,25 мм | предупреждение: это предел подгонки (переливка текста) |
| 2 | нет `icon_align.py` / Python-модулей / `node` | ошибка, макет не изменён |
| 3 | ошибка InDesign | ошибка, смотрите журнал |

Из командной строки шаг запускается отдельно:

```bat
cd D:\instal\Progect2026\9_InpurtTV
python tv_icons.py --indd "D:\instal\Progect2026\8_Programs\Programs.indd"
python tv_icons.py --indd "...\Programs.indd" --check-only      # только замер
```

Ключи: `--check-only` (замерить, не двигать), `--rounds N` (проходов, по умолчанию 8),
`--no-montage`, `--no-sig`, `--keep N` (снимков), `--quiet`.
Контрольная сетка «значок + название» по дням и каналам остаётся в
`_work\icons\work_Programs\montage.png` — по ней проверяют результат зрением.

### Экспорт PDF из командной строки

cd D:\instal\Progect2026\9_InpurtTV
python tv_pdf.py --indd "D:\instal\Progect2026\8_Programs\Programs.indd" --pdf "D:\выход.pdf"

## Запуск

```bat
cd D:\instal\Progect2026\8_Programs
python tv_import.py "program_NEW13102027.txt" --monday 2026-10-19 --issue-date 2026-10-14
```

Инструмент **сам запускает InDesign 2024**, если тот не открыт, открывает макет,
пересобирает все 7 колонок, ставит шрифты и разделители, обновляет даты,
заголовок полосы и шапку, сохраняет файл и печатает отчёт.

> Первый запуск занимает около 2 минут — это холодный старт InDesign.
> Последующие — около 1,5 минут.

### Ключи

| Ключ | Назначение |
|---|---|
| `--monday ГГГГ-ММ-ДД` | **обязательный.** Понедельник недели программы |
| `--monday auto` | Взять дату из имени файла (`program_NEW13102027.txt` → 13.10.2027) |
| `--issue-date ГГГГ-ММ-ДД` | Дата выхода газеты — **обновляет шапку полосы** |
| `--issue-number N` | Номер выпуска в шапке (по умолчанию сохраняется текущий) |
| `--run-number N` | Номер тиража в скобках (по умолчанию сохраняется) |
| `--indd ПУТЬ` | Файл макета. По умолчанию `Programs.indd` рядом со скриптом |
| `--dry-run` | Только показать план, макет не трогать |
| `--quiet` | Краткий вывод |

### Проверка без риска

```bat
python tv_import.py "program_NEW13102027.txt" --monday 2026-10-19 --dry-run
```

Показывает разбор файла: сколько дней, сколько передач, сколько у каждого
канала, какая неделя, заголовок и новая шапка. Макет не изменяется.

## Что делает инструмент

1. **Резервная копия** макета создаётся автоматически перед любым изменением.
2. **Пересобирает 7 колонок** полосы (по одной на день недели) содержимым
   из файла программы.
3. **Размечает шрифты:**
   - весь текст программы — **OctavaC Regular, 7 pt, интерлиньяж 7**;
   - названия каналов **ПЕРВЫЙ, РОССИЯ 1, НТВ, ТВЦ, СЕЙМ** — **OctavaC Bold, 7/7**.
4. **Ставит пустой абзац-разделитель** перед РОССИЯ 1, НТВ, ТВЦ, СЕЙМ
   (4 на колонку, 28 на полосу).
5. **Обновляет** названия дней, даты (7 шт.) и заголовок полосы.
6. **Обновляет шапку полосы** на мастере — дату выхода, а при указании
   номер выпуска и тираж. Например: `15 июля 2026 г. №29 (7897)` →
   `14 октября 2026 г. №42 (7897)`. Шапка правится **только при заданном
   `--issue-date`**, номер выпуска и тираж сохраняются, если их не передали.
7. **Проверяет результат** и пишет отчёт `ОТЧЁТ_ИМПОРТА_ТВ_ГГГГММДД.md`.
8. **Хранит 5 последних резервных копий**, старые удаляет автоматически
   (ручную `Programs_РЕЗЕРВ_ДО_ЗАМЕНЫ.indd` не трогает).

### Про тираж и номер выпуска
Инструмент **не придумывает** эти данные. Если передать только `--issue-date`,
номер выпуска и тираж останутся такими, как были. Если они должны измениться —
передайте явно:

```bat
python tv_import.py "program.txt" --monday 2026-10-19 ^
                    --issue-date 2026-10-14 --issue-number 42 --run-number 7910
```

## Формат файла программы

```
ТЕЛЕВИЗИОННАЯ ПРОГРАММА
==================================================

ПОНЕДЕЛЬНИК
------------------------------

ПЕРВЫЙ
05.00 Добрый УТРЯК 0+
09.00, 12.00, 15.00, 03.00 Новости
09.25 Модный приговор 0+
...

РОССИЯ 1
05.00 Утро России 12+
...

НТВ
...
```

Требования к файлу:

- ровно **7 дней** недели, начиная с понедельника;
- в каждом дне ровно **5 каналов**: `ПЕРВЫЙ`, `РОССИЯ 1`, `НТВ`, `ТВЦ`, `СЕЙМ`;
- передача начинается со времени: `ЧЧ.ММ Название 12+`;
- кодировка **UTF-8**;
- порядок дней в файле может быть любым — инструмент расставит их
  в правильном порядке сам.

При нарушении инструмент остановится и напишет, что именно не так.

## Известное ограничение: нехватка места

Рамка колонки — **126 мм**, кегль 7 pt. Этого хватает примерно на
**600–610 передач** из 688. Если в неделе больше передач (обычно вытягивает
канал СЕЙМ), хвост списков не помещается и не печатается.

Инструмент это **показывает в отчёте** построчно по дням — сколько внести
удалось, а сколько нет.

Что делать, если передач не хватает (в порядке предпочтения):

1. сократить ночные повторы СЕЙМ — обычно они самые длинные;
2. уменьшить интерлиньяж в колонках с 7 до 6 pt (правится в макете,
   инструментом не трогается, чтобы не менять типографику полосы без спроса).

## Устройство

```
tv_import.py        основной инструмент: разбор, генерация, проверка
_winax_runner.js    мост Node -> InDesign 2024 (winax)
_work/              временные файлы (создаётся при запуске)
```

**Требования:** Python 3, Node.js, InDesign 2024, модуль `winax`
(ставится вместе с пакетом `indesign-cli`; путь ищется автоматически).

## Полезные приёмы

Проверить, что инструмент ничего не сломал, можно повторным запуском —
он идемпотентен: если всё уже верно, разметка покажет «исправлено 0».

```bat
python tv_import.py "program_NEW13102027.txt" --monday 2026-10-19
```

Если макет открыт в InDesign — всё работает, инструмент подхватит открытый
документ. Если открыт **другой** макет с таким же именем — инструмент
сначала закроет лишние и откроет нужный.

**Время работы:** около 1,5–3 минут. Большая часть — InDesign пересобирает
7 колонок по ~110 абзацев и проверяет шрифты в несколько проходов.
